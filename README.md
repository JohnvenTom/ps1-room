# PS1 Scenes — 仿射纹理蠕动还原 · 九场景

> 一个**单 HTML 文件、零网络请求**的 PlayStation 1 渲染管线还原演示：在浏览器里用 Three.js + 手写 GLSL 完整复刻 PS1 时代的仿射纹理映射（Affine Texture Mapping）、顶点吸附抖动（Vertex Wobble）、RGB555 色深 + Bayer 抖动、低分辨率渲染与全套 CRT 滤镜，并附带实时点光源/方向光阴影、距离雾、天空穹顶、粒子系统与第一人称漫游。现已内置 **9 个可切换场景**：密封房间、黄昏神社、浓雾夜小镇、中世纪集市、赛博雨巷，以及雪岭驿站、大漠驿站、江南水乡夜、太空舷窗四个新成员。

![overview](docs/images/08-shrine.png)

双击打开 [`index.html`](index.html) 即可运行——不需要服务器、不需要 `npm install`、不发起任何网络请求（Three.js r159 已整体内联，所有贴图均为运行时程序化生成）。按 <kbd>N</kbd> 在九个场景间循环切换，URL 加 `#scene=0..8` 可直达指定场景。

## 技术解析

### 渲染管线总览

```
                 ┌────────────────────────────┐
 场景几何+道具 ──▶│ Pass 1: 320×240 RenderTarget│  自定义 PS1 ShaderMaterial
 (世界坐标烘焙)   │  · 仿射 UV / 顶点吸附       │  · 顶点色 Gouraud
 + 天空穹顶      │  · RGB555 + Bayer 抖动      │  · 阴影采样 ×0.35 压暗
 + 粒子          │  · 逐场景距离雾              │  · 彩色多光源已烘进顶点色
                 └────────────┬─────────────┘
                                │ Nearest 整数倍放大
                 ┌────────────▼─────────────┐
 全屏三角 ──────▶│ Pass 2: CRT Shader          │ 扫描线/荫罩/畸变/色差/噪波
                 └────────────┬─────────────┘
                                │
                     canvas（4:3 letterbox 居中）
```

另有独立的**阴影 Pass**：房间场景 `WebGLShadowMap` 渲染点光源 6 面立方体图集（256²/面）；室外场景渲染方向光正交阴影（1024²），供 Pass 1 的片元着色器采样。

### 仿射纹理映射

现代 GPU 对三角形顶点属性做透视校正插值，PS1 没有。做法是在顶点着色器把 UV 先乘上 `w`，插值后再除一次 `w`——由于插值发生在裁剪空间之后，除法得到的就是**未经透视校正**的屏幕空间线性 UV：

```glsl
// vertex
vAff = vec3(uv * clip.w, clip.w);
// fragment
vec2 u = vAff.xy / vAff.z;   // 透视分量被"错误"地约掉 → 贴图蠕动
```

`1` 键即在 `vAff.xy / vAff.z` 与原始 `vUvP` 之间切换，是同屏对比两种插值的活教材。

### 顶点吸附（Vertex Snapping）

PS1 几何变换输出定点数，顶点位置量化到帧缓冲整像素，相机平移时顶点在像素网格里跳变，产生著名的 polygon judder。在 320×240 空间内实现：

```glsl
vec2 hs = uRes * 0.5;
vec2 px = clip.xy / clip.w * hs + hs;
px = floor(px) + 0.5;                       // 吸附到整像素中心
clip.xy = (px / hs - 1.0) * clip.w;
float wq = floor(clip.w * 32.0) / 32.0;     // 深度量化：视深按 3 cm 分桶 → z-fighting 闪烁
clip.z = -projectionMatrix[2][2] * wq + projectionMatrix[3][2];
```

深度量化刻意选在**视空间线性**分桶：透视深度高度非线性，全局 256 桶在 6 m 处一档就覆盖 1 m 以上世界深度，近邻表面会整块互相"穿模"顶掉贴图；3 cm 线性桶既保留掠射角下的经典 PS1 闪烁，又保证近邻表面稳定分层。粒子系统与贴花共用同一段吸附代码。

### RGB555 + Bayer 抖动

PS1 帧缓冲为 15-bit 色深。先用 4×4 Bayer 矩阵（屏幕空间 `floor(mod(gl_FragCoord.xy, 4.0))` 取索引）加半级噪声，再截断到 31 级：

```glsl
c = clamp(c + (b - 0.5) * (1.5 / 32.0), 0.0, 1.0);
c = floor(c * 31.0 + 0.5) / 31.0;
```

同一张 Bayer 贴图被复用于阴影半影、接触阴影、贴花镂空、粒子渐隐与**天空穹顶**，保证全画面"网点语言"一致。

### 场景光照：顶点烘焙 + 彩色多光源

所有场景不含任何实时光照方程：几何构建时以该场景的光照函数逐顶点烘焙亮度写入顶点色，由光栅化 Gouraud 插值。这是 PS1 的标准做法，也因此天然支持**彩色多光源**——烘焙函数返回 RGB 三通道：

- **房间**：吊灯单点光源（距离衰减 × Lambert），每帧乘共享 `uFlicker`（双正弦 + 随机电压跌落）模拟钨丝呼吸；
- **室外**：平行光（夕阳/月光，N·L 朝向项，无距离衰减）+ 半球环境光（法线朝上混天光、朝下混地光）；
- **小镇**：在月光之上叠加 5 盏路灯的暖色点光池（`k/(1+d²·c)` 衰减）；
- **雨巷**：5 处霓虹**逐通道**彩色光池（红/品红/青/黄各有独立 RGB 贡献），湿地面上的彩色"倒影"光池是同色贴花。

地面用细分网格（如 11×11）烘焙，光池以逐顶点 Gouraud 块状渐变呈现——低密度顶点光正是 PS1 夜景的经典质感。发光体（灯泡/灯笼窗/霓虹面/贩卖机面板）不走烘焙，直接写 >1 的顶点色。

### 实时阴影：点光源与方向光双管线

Three.js 的 `ShaderMaterial` 默认不参与阴影系统，本项目通过标准管线打通（材质 `lights: true` + 注入官方 shadowmap chunk，片元端手写采样数学）。两套阴影共存于同一着色器，由 `NUM_POINT_LIGHT_SHADOWS` / `NUM_DIR_LIGHT_SHADOWS` 编译期开关——每个场景恰有一盏投影主光，程序按场景光源配置自动编译对应分支：

- **点光源**（房间）：256² 立方体图集 ×6 面，方向向量 → `cubeToUV()` → 深度比较；
- **方向光**（室外）：1024² 正交阴影贴图覆盖全场，投影正交盒 ±14~22 m；
- 两者共用 **Bayer 半影**：深度差窗口内与屏幕空间 Bayer 阈值比较，硬边切出有序抖动的过渡带；阴影只作乘性压暗（×0.35）保持顶点烘焙为亮度基底；
- 摆动/游动/旋转的道具（摆灯、锦鲤、车轮）阴影自动跟随——物体矩阵变换由阴影 Pass 天然支持；
- `7` 键同时关掉阴影贴图与接触阴影贴片；污渍/苔藓/光池贴花常驻（脏污不是阴影）。
- **贴花深度分层（防闪烁）**：视深量化按 3.125 cm 分桶后，浮高小于一桶的贴花会与底面落进同一桶、深度完全相等——相机微漂移时两者胜负逐帧翻转，这就是"贴花在底面上闪烁"的根源。修复分两手：① 贴花顶点着色器在量化后把深度**前移 0.75 个桶**（以桶为单位偏移，任何视距都正确），并按类别分层（污渍 0.75 / 光池 1.1 / 接触阴影 1.6），贴花互相叠放也永不共桶；② 所有"贴面薄片"（霓虹面/贩卖机面板/灯笼发光窗/窗户贴片/书架书脊面）的物理间距抬到 ≥ 4 cm（大于一桶）。已用两个不同相机时刻的截图对比贴花区域色统计（差异 < 1/255）验证稳定。

### 距离雾与天空穹顶

PS1 主机显存有限，距离雾是那个时代隐藏裁剪距离的标准手法（寂静岭把它用成了美学）。片元端按视空间距离做 `smoothstep(fogNear, fogFar, vDist)` 混合，且**雾在 RGB555 量化之前**执行——雾本身也带网点抖动。天空穹顶是一个 90 m 反向球面，片元程序化生成：地平线→天顶渐变、太阳/月亮圆面 + 辉光、hash 星点（夜场景，带闪烁），最后过同一套 RGB555 + Bayer 量化。关键约束：**每场景雾色 == 天穹地平线色**，几何体没入雾中时与天幕无缝衔接。穹顶不做顶点吸附（半径 90 m 的吸附抖动会是地震级）。

### 粒子系统

单个 `THREE.Points` 着色器四种模式（`uMode` 分支），位置由种子属性 + 时间在顶点着色器程序化求出（无 CPU 逐帧更新）：花瓣（慢速摇曳下落 + 双正弦摆动）、雨（快速斜落）、蒸汽（上升 + 半径扩散 + 高度渐隐）、浮尘（超慢漂移 + 亮度呼吸）。配色与参数即氛围：金色浮尘（集市）、黄绿浮尘=萤火虫（神社池塘黄昏）、橙色高速蒸汽=火焰（集市火盆）、灰白慢蒸汽=香炉烟/炊烟/巷口蒸汽。粒子走同一顶点吸附管线（会跟着抖动，浑然一体），片元以 Bayer 阈值 discard 实现渐隐/软边，点大小按视距缩放。切换场景时各场景粒子随整场景换装；`9` 键总开关。

### CRT 滤镜

第二遍全屏三角采样 320×240 结果，逐像素执行：桶形畸变 → 每通道径向色差 → 隔行扫描线 → RGB 三列荫罩掩膜 → 移动噪波带 + 全画面颗粒 → 暗角 → 低频亮度呼吸。`5` 键关闭后即为"纯像素"参考图。

### 相机系统：微漂移与漫游

**为什么需要待机漂移**：若相机与场景完全静止，仿射蠕动每帧渲染结果相同、效果不可见。待机模式让相机以 ±2 cm / ~1.5° / 20 s 周期微动，蠕动与顶点抖动持续可见。每场景有独立设计的待机取景（神社沿参道望向神社、小镇望向雾深处、集市望向喷泉、雨巷望向巷子尽头）。

漫游模式以 Pointer Lock 优先、但不硬依赖它：点击或 <kbd>M</kbd> 切换行走状态并尝试锁定指针。在锁定被拒绝的环境下自动回退为**按住左键拖拽转向**（未锁定时 OS 光标回中会产生巨大 `movementX` 尖峰，因此回退路径只认拖拽，并保留 ±260 px/帧尖峰钳制双保险）。其余移动特性：场景边界钳制、道具 AABB 碰撞（人体半径 0.35 m）、步伐起伏；停止输入 3 秒后以四元数 slerp + 位置 lerp 平滑交还待机漂移。<kbd>N</kbd> 切场景时黑屏淡入淡出，相机与碰撞体整套热替换。

### 程序化贴图

30 余张 64×64 贴图全部在运行时用 JS 像素循环生成，按场景分组：房间 8 张（地砖/水泥墙/木板/油桶/管道/格栅/封板窗/书脊）；神社 8 张（耙纹碎石/花岗岩/朱红漆/水面/树皮/红叶团/木板/瓦屋顶）；小镇 8 张（湿沥青+车道线/人行道板/三种木墙板/两种屋瓦/锈金属/夜草）；集市 10 张（卵石/石膏/木梁/红绿条纹篷/石器/水/麻布/木瓦/条旗）；雨巷 8 张（湿沥青/砖墙/混凝土/卷帘门/金属/四张像素汉字霓虹/贩卖机面板）。"零网络"约束下不存在任何外部素材文件，贴图风格参考 PS1 时代实机截图。

## 设计取舍与已知说明

- **阴影是"乘性因子"而非光照**：保持顶点烘焙为亮度基底，阴影只负责压暗——逐像素动态光会破坏 PS1 观感，属于刻意取舍。
- **每场景恰一盏投影光**：点光立方体与方向光正交两套采样共存于同一着色器，由场景光源配置在编译期选择；多盏投影光的性能预算在 320×240 目标下不予考虑。
- **室外无仿射地面"蠕变"穿帮**：大面积地面/天空在低分辨率下的仿射弯曲是刻意保留的 PS1 味道，`1` 键可对照。
- **天穹不做顶点吸附**：90 m 半径的整像素吸附会产生地震级抖动；天穹以自身渐变 + 网点量化呈现，其余一切几何（含粒子）照常抖动。
- **霓虹"倒影"是贴花不是镜面**：湿地面彩色光池为同色 Bayer 贴花，真实平面反射不在 PS1 语法内。
- **默认 affine OFF**：启动画面以清晰几何 + 阴影为主展示，蠕动通过 `1` 键一键对比；顶点抖动（默认 ON）保证启动即有"活"的质感。
- **`file://` 直开**：本文件不加载任何外部资源，双击即可运行；个别浏览器对本地页限制 WebGL 时，用任意静态服务器打开即可。
- **性能**：阴影贴图每帧重渲染当前场景一盏投影光；实测 1280×960 窗口、五场景阴影/雾/粒子全开均稳定 60+ FPS；着色器较多，首次打开有短暂编译时间。

## 浏览器要求

- 支持 **WebGL**（Three.js r159）的现代桌面浏览器：Chrome / Edge / Firefox 均可；
- 键盘交互（数字键 1–9、`[` `]`、`N`、`M`、`WASD`）；
- 无移动端适配（漫游依赖键盘与鼠标 `movementX/Y`）。
